# Mildly Impossible

Small household tasks that are technically possible. There are a thousand tutorials for each of them. This is the practice room.

A collection of mouse-only browser toys in the spirit of neal.fun.

- **Carry a Full Mug**: carry a mug filled to the brim across the room without spilling on the rug. Or the cat.
- **Fold a Fitted Sheet**: four elastic corners, one rectangle.

Live: https://impossible-chores.higgsfield.app

## Run it locally

```bash
cd app
bun install
bun run dev
```

Built with TanStack Start (React 19) and plain canvas 2D. See `CLAUDE.md` for how the code is organized and how it ships.
